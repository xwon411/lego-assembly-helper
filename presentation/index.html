01문제

단계 정보 없는 설계 파일

부품 위치만 있고 조립 순서는 없음 → 따라 만들기 어려움

  • 레고 설계 파일(LDraw)은 부품 하나하나의 모양·색·좌표를 적은 텍스트
  • 조립 단계는 파일 안에 STEP이라는 표시를 따로 넣어야 생기는데, 이걸 빠뜨린 파일이 많음
  • 단계가 없으면 수백 개 부품이 한꺼번에 보임 → 어디부터 쌓아야 할지 모름
  • 사람이 대신 순서를 정하려면 모델마다 시간이 많이 듦
