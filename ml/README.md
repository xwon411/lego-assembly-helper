# 조립 순서 학습 (진행 중)

단계 정보(STEP)가 없는 설계 파일의 조립 순서를 학습으로 만들기 위한 실험.

- `extract.py` — 앱(index.html)을 헤드리스로 열어 모델별 부품 상자·정답 단계·지금 규칙 방식 단계를 `feat/*.json`으로 저장
- `order.py` — 1차: 부품 쌍 "누가 먼저?" 분류 → 전체 순위 (쌍 정확도 규칙 61.3% → GB 68.9%)
- `next.py` — 2차: "지금까지 조립한 상태에서 다음 단계 부품은?" 분류 (다음 부품 적중률 규칙 11% → 약 50%)
- 데이터: three.js 저장소의 LDraw 공식 모델 중 STEP이 있는 13개 (부품 2,016개)
- 평가: 모델 하나씩 빼고 학습(leave-one-model-out), 모델별 평균

다음: OMR 모델 20~30개 추가 → 재학습, 앱 적용

## 앱 적용 (2026-11-22)
- 데이터: 13개 → OMR에서 받은 52개를 더해 **65개 세트** (`ml/pack.py`로 부품 포장, `ml/extract.py`로 추출)
- 최종 모델: 그래디언트 부스팅 200그루, 특징 23개 (21개 + 규칙 순서 힌트 2개). `USE_RULE=1 python3 ml/export.py` → `ml/model.json` (앱 `index.html`의 `#ai-model`에 같은 내용)
- 5겹 교차검증, 전체 순서 쌍 정확도: **규칙 58.3% → AI 60.2%** (65개 중 38개에서 AI가 나음), 단계 수 평균 규칙 33.5 / AI 36.6 / 정답 43.5
- 다음 부품 적중률(규칙 힌트 없이): 무작위 10.4% / 규칙 6.9% / AI 55.0%
- JS 이식 확인: `python3 ml/parity.py car 4915 6344-1 1472-1 10174` → 파이썬과 순서 100% 일치. 1065개 부품에 4초(테스트 환경) → 앱은 800개 이하에서만 AI 사용
